# Practical 10 – Wine Dataset Analysis Using EDA, Scaling and PCA

## Overview
This practical performs Exploratory Data Analysis (EDA), data visualization, feature scaling and Principal Component Analysis (PCA) on the Wine dataset. The objective is to understand the dataset, explore relationships between features and visualize the separation of different wine classes.

## Dataset Information
- **Dataset Name:** Wine Dataset
- **Source:** Scikit-learn built-in dataset
- **Total Observations:** 178
- **Total Features:** 13 independent features
- **Total Columns:** 14 (including target)
- **Target Variable:** target
- **Number of Classes:** 3

## Features Used
1. Alcohol
2. Malic Acid
3. Ash
4. Alcalinity of Ash
5. Magnesium
6. Total Phenols
7. Flavanoids
8. Nonflavanoid Phenols
9. Proanthocyanins
10. Color Intensity
11. Hue
12. OD280/OD315 of Diluted Wines
13. Proline

## Wine Classes
- Class 0
- Class 1
- Class 2
